# AIC 4.0 — All-in-One Class

수업 운영, **집중 모니터링**, **활동 보드(패들렛형)**, **PDF 학습지·문제**, **화면 공유**를 한 화면에 모은 교실용 웹 앱입니다.
학생은 계정 없이 QR/6자리 코드와 이름만으로 참여하고, 선생님은 **Cloudflare에 둔 비밀번호 하나**로 입장합니다.

## v4의 핵심: 비밀번호 게이트 + 즉시 파기

- **선생님 계정 가입/로그인 없음.** `/login`에서 비밀번호만 확인하며, 값은 Cloudflare secret `TEACHER_PASSWORD`에만 있습니다.
  표시 이름은 처음에 `TEACHER_NAME`(없으면 ‘선생님’)으로 만들고, 이후 **대시보드에서 ‘이름 바꾸기’**로 언제든 바꿉니다.
- 수업을 종료하면 참가자·퀴즈·게임 응답·학습지 제출·보드 사본·이벤트가 **즉시 삭제**됩니다. 24시간 보관하지 않습니다.
- **R2를 쓰지 않습니다. 대용량 업로드도 없습니다.** D1에는 수업 요약과 임시 참가자만 저장합니다.
- 활동 보드와 학습지 PDF는 **선생님 브라우저(IndexedDB)** 에만 저장됩니다.
- 선생님이 수업 콘솔에서 보드를 열거나 PDF를 배포한 동안에만 학생에게 전달되고,
  콘솔을 닫으면 학생 화면에서 사라집니다. 실수로 새로고침해도 10초 안에 다시 연결되면 보드가 유지됩니다.
  PDF는 학생이 요청할 때 소켓으로 조각 전송될 뿐 서버에 보관되지 않습니다.
- 화면 공유는 **WebRTC P2P**입니다. 선생님 화면을 학급에 보내고, 학생이 직접 허용한 화면을 선생님이 볼 수 있습니다.
  영상은 저장하지 않습니다. 학생은 입장할 때 전체화면과 화면 공유를 함께 시작할 수 있습니다.
- **입력 관찰**은 선생님이 켠 동안 AIC 안의 학습지·보드·게임 입력만 미리 보여 줍니다.
  다른 앱, 비밀번호 필드, 키보드 전체 입력은 수집하지 않습니다.
- **학습지 탭**에서 문제(3~6지선다·OX·주관식·뜻 연결)를 만들고, 마감 후 **결과를 학생 화면에 크게 띄웁니다**(응답 수·선택지 분포·정답자).
  **일반전·스피드전(빠를수록 고득점)·골든벨(틀리면 탈락)·팀전(모둠 합산)·아이템전**과 문제별 제한 시간,
  **대기 화면(방번호+접속 학생)**, **랭킹판(순위·점수 막대·알림 피드)**, 실시간 순위표를 지원합니다.
  문제 유형은 **3~6지선다·OX·주관식 단어·뜻 연결**을 직접 편집할 수 있고, 아이템전에서는 정답마다 더블·훔치기·+50점 아이템을 받아 씁니다.
  **제한 시간 마감은 서버(Durable Object 알람)가 처리**하므로 선생님이 다른 탭을 보거나 콘솔을 닫아도 제때 마감됩니다.
- **모둠·도구 탭**에서 **모둠 점수판**(+1/+5/+10, 학생 화면에도 표시)과 **출석 체크**(학생 출석하기 버튼),
  **소음 측정기**(마이크 음량만 측정, 저장 없음), **스톱워치**(구간 기록)를 씁니다.
- **모둠·도구 탭**에서 발표자를 무작위로 뽑고, 모둠 수(1~8개)를 늘리거나 줄여 자동 배분하며, 학생이 직접 모둠을 고르게 할 수 있습니다. 선생님이 학생을 골라 **모둠을 직접 배정**할 수도 있습니다.
  **자리 뽑기**는 줄(행)·한 줄 인원(열)을 골라 무작위로 배치하고, 학생을 골라 특정 자리로 옮기거나 비울 수 있으며,
  **학생이 직접 빈자리를 고르게** 할 수도 있습니다. 모둠별 토의는 **각 모둠의 글만 그 모둠 학생에게** 전송되어 다른 모둠 글은 보이지 않습니다.
- **학습지**는 PDF만 보는 것이 아니라 AIC 안에서 단답·서술·O/X 문항을 직접 풀고 제출합니다. 정답을 넣어 두면 자동 채점되고, 제출 현황을 CSV로 저장할 수 있습니다.
  한 번 제출하면 잠기며(재제출 불가), 선생님이 **다시 제출 허용**을 눌러야 수정할 수 있습니다. 학생 답안과 모범 답안은 전체 화면에 띄울 수 있습니다.
  PDF 필기는 **메모만 저장** 또는 **원본+메모 PDF**로 내려받습니다.
- **활동·띄우기 탭**에서 웹 페이지·큰 글씨 안내문·활동 보드를 접속한 모든 학생 화면에 동시에 띄우고, 이 링크 보내기로 링크+알림을 한 번에 보냅니다. 활동 보드·패들렛·화면 공유도 같은 탭에 모여 있습니다.
  50분 수업 타이머는 학생 화면 상단에 함께 표시되며, 손든 학생과 전체 알림도 이 탭에서 관리합니다.
- 같은 탭의 **패들렛** 카드에서 주소·embed 코드를 그대로 붙여 넣으면 공개 보드를 앱 안에서 바로 쓸 수 있습니다.
- 대시보드의 휴지통 버튼으로 **수업을 완전히 삭제**할 수 있습니다(참가자·응답·보드 사본·이벤트 즉시 삭제, 로컬 파일은 유지).
- 집중 이벤트는 여전히 "관측된 사실"로만 기록하며 부정행위로 판정하지 않습니다.

## 스택

React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · React Router 7

> 객체 저장소(R2)와 미디어 업로드 파이프라인은 v3에서 제거되었습니다. v4는 단일 비밀번호 게이트를 사용합니다.

## 빠른 시작

```bash
bun install
bun run db:local      # 로컬 D1에 database/migrations 적용
bun run dev           # Worker(8787) + Vite(5173) 동시 실행
```

브라우저에서 <http://127.0.0.1:5173> 을 엽니다. Vite가 `/api`와 WebSocket을 `127.0.0.1:8787`로 프록시합니다.
로컬 비밀번호는 `.dev.vars`의 `TEACHER_PASSWORD`(기본 `aic-class-2026`)입니다. 이 파일은 git에 포함되지 않습니다.

> **Bun + Wrangler 주의**: 이 환경에서는 Bun으로 `wrangler dev`를 띄우면
> `Wrangler does not support the Bun runtime` 경고와 함께 워커가 종료되고,
> **모든 요청이 503 Service Unavailable**로 떨어집니다(로그에는 `script "dev:api" exited with code 1`).
> 그럴 때는 Node 20+로 Worker만 따로 실행하세요.
>
> ```bash
> node node_modules/wrangler/bin/wrangler.js dev --port 8787 --local
> bunx vite --port 5173 --host 127.0.0.1
> ```

### 다른 기기(폰·태블릿)에서 접속

브라우저는 `http://` 주소에서 `crypto.subtle`·`navigator.clipboard`·`getDisplayMedia`를 숨깁니다.
같은 네트워크의 다른 기기에서 PDF 배포·복사·화면 공유를 모두 쓰려면 **HTTPS 주소**로 열어야 합니다.

```bash
bun run dev:lan                        # Worker(8787) + Vite(0.0.0.0:8000)
bash scripts/make-lan-cert.sh          # 자체 서명 인증서 생성 (.certs/, gitignore)
bun run dev:https                      # https://<이 PC IP>:8443
```

- `https://100.95.131.112:8443` 처럼 `https://` + 같은 IP로 엽니다. 인증서 경고는 **고급 → 계속**으로 한 번만 넘기면 됩니다.
- Tailscale을 쓰면 Serve를 켜서 경고 없는 주소를 얻을 수 있습니다: `tailscale serve --bg 8000` → `https://<기기이름>.<tailnet>.ts.net`.
- `http://…:8000` 으로 열어도 PDF 배포와 복사는 동작합니다(대체 해시·복사 경로). **화면 공유만** HTTPS가 필요합니다.
- iPhone/iPad Safari는 `getDisplayMedia`를 지원하지 않습니다. 학생 화면 공유는 노트북이나 Android Chrome에서 확인하세요.

### 수업 당일: 안정 모드(빌드 결과물로 열기)

개발 서버(5173)는 파일을 고칠 때마다 새로 고쳐지므로, 수업 중에는 **빌드 결과물**을
`vite preview`로 띄우는 편이 안전합니다. 새로고침이 필요 없고 학생 기기에서도 빠릅니다.

```bash
bun run build        # dist/client 생성
bun run preview      # 0.0.0.0:8000 (앱 + /api 프록시)
```

- 선생님은 `http://<이 PC IP>:8000`으로 콘솔을 열고 로그인합니다(예: `http://192.168.45.177:8000`).
- 학생은 같은 주소의 QR/링크로 입장합니다. 이 주소는 **127.0.0.1이 아니므로** 폰에서 그대로 열립니다.
- 코드를 고쳤을 때만 `bun run build`를 다시 실행하면 됩니다(개발 중에는 `bun run dev` 그대로).

> **폰에서 페이지가 안 열릴 때**는 Windows 방화벽이 Node를 막고 있을 가능성이 큽니다.
> Windows 보안 → 방화벽 및 네트워크 보호 → **앱이 방화벽을 통과하도록 허용** → `Node.js`의
> **개인 네트워크**를 체크하세요. 같은 와이파이에 있는지도 확인합니다.

### 인터넷에 배포 (Cloudflare Pages + Workers)

실시간 수업방은 **Durable Objects**를 쓰기 때문에 Pages Functions에 직접 바인딩할 수 없습니다.
그래서 이 저장소는 **Pages = 정적 파일 + `/api/*` 프록시**, **Workers = API/WebSocket** 구조로 배포합니다.

```
브라우저 → https://all-in-one-class.pages.dev      (React 번들, CDN)
         → /api/* ─ functions/api/[[path]].ts ─→ https://aic.<계정>.workers.dev  (D1 + Durable Objects)
```

- 프록시가 `Origin`을 Worker 주소로 맞춰 주므로 same-origin 검사·쿠키·WebSocket이 브라우저에서는
  모두 한 주소처럼 동작합니다.
- Worker 배포: `wrangler deploy` (D1 `aic-db`, DO `ClassroomHub`, 시크릿 `TEACHER_PASSWORD`·
  `SESSION_SECRET`·`TEACHER_NAME`).
- Pages 배포: `vite build` 후
  `wrangler pages deploy dist/client --project-name all-in-one-class --branch main`.
- Pages 프로젝트 이름을 바꾸면 `functions/api/[[path]].ts`의 `API_ORIGIN`만 맞춰 주면 됩니다.

### 처음 확인하는 순서

0. 앱 안의 **기능 안내**(`/app/guide`)에 열두 개 탭과 학생 화면 기능, 배포 전 설정 목록이
   정리되어 있습니다. 수업 중 새 탭으로 열어 두어도 됩니다.
1. `/login`에서 선생님 비밀번호로 입장합니다(로컬 기본 `aic-class-2026`).
2. 대시보드 → **활동 보드**에서 템플릿으로 보드를 하나 만듭니다.
3. **새 수업 만들기** → 수업 콘솔로 이동합니다.
4. 다른 브라우저/시크릿 창에서 `/join/<참가코드>`를 열고 이름만 입력해 참여합니다.
5. **학습지·문제** 탭에서 문항을 만들고(또는 PDF를 붙이고) **학습지 배포**를 누릅니다.
   학생 화면에서 답을 쓰고 **학습지 제출**을 누르면 선생님 화면에 점수와 함께 나타납니다.
6. **학습지** 탭에서 문제를 만들고(빠른 양식) **문제 시작**을 누릅니다.
7. **띄우기·타이머** 탭에서 안내문이나 주소를 띄우고, 50분 타이머를 시작합니다.
8. **화면 공유** 탭에서 선생님 화면을 공유하거나, 학생 카드의 **화면 요청** → **크게 보기**로
   학생 화면을 프로젝터에 띄웁니다.
9. **수업 종료** 후 대시보드에서 참가자가 0명인지, 내용이 비워졌는지 확인합니다.
   기록을 남기고 싶지 않다면 대시보드 카드의 휴지통으로 **수업 삭제**까지 하면 됩니다.

## 50분 수업 사용법

> 같은 내용을 앱 안에서도 볼 수 있습니다: 로그인 후 사이드바 **기능 안내**(`/app/guide`).

### 0) 수업 전 준비 (5분)

- `/app/boards`에서 오늘 쓸 **활동 보드**를 미리 열어 두거나 템플릿으로 새로 만듭니다.
- **학습지·문제** 탭에서 PDF를 고르고, 필요하면 단답·서술·O/X 문항을 만들어 둡니다.
  정답을 입력한 문항은 제출 즉시 자동 채점됩니다.
- 휴대폰·태블릿은 **HTTPS 주소**로 접속해야 화면 공유가 됩니다. (아래 “다른 기기에서 접속” 참고)

### 1) 입장 (0~3분)

1. 대시보드 **새 수업 만들기** → 수업 콘솔이 열립니다.
2. 상단 **참가 안내**의 QR 또는 6자리 코드를 칠판에 띄웁니다.
3. 학생은 `/join/<코드>`에서 **이름만** 입력하고 입장합니다. 계정은 만들지 않습니다.
4. 콘솔 **수업 현황**에서 접속 인원과 전체화면 상태를 확인합니다.

### 2) 학습지 (3~15분)

- **학습지·문제** 탭 → 안내 문구 입력 → **문항 추가**(단답/서술/O/X) 또는 **PDF 선택** → **학습지 배포**.
- 학생 화면에 문항 입력칸과 PDF가 함께 나타납니다. 학생은 답을 쓰고 **학습지 제출**을 누릅니다.
- 선생님 화면 오른쪽에 학생별 답과 점수가 실시간으로 쌓입니다. **CSV 저장**으로 제출 현황을 내려받을 수 있습니다.
- PDF는 선생님 컴퓨터에서 학생이 **받기**를 누를 때만 전송됩니다. 서버에는 저장되지 않습니다.
- 받은 PDF는 앱 안에서 바로 보며 **펜·형광펜·지우개**로 메모할 수 있습니다. 메모는 그 학생의
  브라우저에만 저장되고, **메모만 저장**(필기한 페이지만) 또는 **원본+메모 PDF**로 내려받을 수 있습니다.
- 학습지는 **한 번 제출하면 잠깁니다.** 더 고치려면 선생님이 **학습지·문제** 탭에서 **다시 제출 허용**을 누릅니다.

### 3) 실시간 문제 확인 (15~30분)

- **학습지** 탭 → 왼쪽에서 문제 만들기 → 마감 후 **결과를 학생에게 띄우기**.
  - **일반전**: 정답 100점.
  - **스피드전**: 정답 + 빠른 정도에 따라 최대 200점.
  - **골든벨**: 한 문제라도 틀리면 탈락. 남은 인원이 순위표에 표시됩니다.
  - **팀전**: 모둠별로 자동 배분되고 모둠 점수가 합산됩니다. **자동 배분**으로 시작 직전에 다시 나눌 수 있습니다.
  - **아이템전**: 정답마다 더블·훔치기·+50점 아이템을 받아 학생이 직접 사용합니다.
- **대기 화면 열기**를 누르면 프로젝터에 방번호와 접속 학생 목록이 크게 나옵니다. 이미 수업에 들어온 학생은
  그대로 참여하고, 첫 문제를 시작하면 대기 화면이 닫힙니다.
- 문제 유형은 **3~6지선다**(선택지 동그라미로 정답 지정)·**OX**·**주관식 단어**·**뜻 연결**(짝 맞히기)을 지원합니다.
- 문제별 **제한 시간**을 걸면 시간이 끝나는 순간 자동으로 응답이 마감되고 정답이 공개됩니다.
- **프로젝터** 버튼을 누르면 큰 문제·카운트다운·응답 수·정답·시상대가 나오는 교실 화면이 열립니다(전체화면 지원).
  상단의 **랭킹판** 탭으로 바꾸면 순위 막대와 ‘○○이 1위’ 알림 피드를 수업 화면에 크게 띄웁니다.
- **결과 CSV**로 순위·점수·정답/오답·모둠을 내려받을 수 있습니다.
- **제한 시간**(없음/20/30/60초)을 고르고 **이 문제 시작**을 누릅니다.
- 학생 화면에 문제·선택지·남은 시간이 뜨고, 응답하면 내 점수와 순위가 함께 보입니다.
- **응답 마감**으로 정답을 공개하고, **다음 문제**로 넘어갑니다. **점수 초기화**는 새 판을 시작합니다.
- 간단한 단일 문제는 **학습지·문제** 탭의 **실시간 문제**에서 바로 낼 수 있습니다.

### 3-1) 모둠 (수시)

- **모둠·자리** 탭에서 **발표자 뽑기**(전체/특정 모둠) → 결과가 모든 학생 화면에 표시됩니다.
- **모둠 수**를 1~8개로 바꾸고 **자동 배분**으로 균등하게 나누며, **학생이 직접 모둠 선택**을 켜면 학생 화면에 모둠 버튼이 생깁니다.
- **자리 뽑기**는 줄(1~8)·한 줄 인원(2~10)을 고른 뒤 눌러 무작위로 배치합니다. 학생을 고른 뒤 자리를 누르면
  이동하고, 앉은 학생을 누르면 비웁니다. **학생이 직접 자리 선택**을 켜면 빈자리를 눌러 앉을 수 있습니다.
- **모둠별 토의**: 학생은 자기 모둠 칸만 보고 글을 씁니다. 다른 모둠 글은 서버에서 전송되지 않습니다.
- **학습지** 탭에서 문제를 내고, 마감하면 결과(응답 수·분포·정답자)를 학생 화면에 크게 띄웁니다.
  - **룰렛** — 무작위 한 명 뽑기.
  - **폭탄 돌리기** — 폭탄을 든 학생이 **넘기기**를 누르고, 터지는 시각은 서버만 압니다. 선생님이 다른 탭에 있어도 터지고, 학생 화면에는 남은 시간이 표시되지 않습니다.
  - **낱말 찾기** — 낱말 2~6개를 넣으면 서버가 12×12 퍼즐을 만들고, 학생은 찾은 낱말을 입력합니다.
  - **카드 짝 맞추기** — 같은 낱말 두 장을 찾는 기억 게임. 학생과 선생님이 함께 카드를 뒤집습니다.
  - **사다리 타기** — 이름·상품·높이를 넣으면 서버가 사다리를 긋고 결과를 계산합니다. **결과 공개**를 눌러야 색깔 길과 당첨이 나타납니다.
  - **초성 퀴즈** — 낱말을 넣으면 서버가 초성(예: ㅅㄱ (2글자))만 보내고, 먼저 맞힌 학생이 10점을 받습니다. **다음 문제**로 이어 갑니다.
- **수업 도구** 탭:
  - **모둠 점수판** — +1/+5/+10으로 점수를 주고, 학생 화면에도 순위와 함께 표시됩니다.
  - **출석 체크** — **출석 받기**를 누르면 학생 화면에 버튼이 뜨고, 누가 냈는지·안 냈는지 바로 보입니다. 명단을 복사할 수 있습니다.
  - **소음 측정기** — 마이크 음량만 재고 소리는 저장·전송하지 않습니다.
  - **스톱워치** — 활동 시간과 구간 기록(교사 화면 전용).

### 4) 보드·패들렛·외부 자료 띄우기 (30~40분)

- **활동 보드** 탭 → 보드 열기 → **학생 화면에 띄우기**. 학생 글쓰기를 켜면 카드가 실시간으로 모입니다.
- **패들렛** 탭 → `padlet.com` 주소 또는 embed 코드 붙여넣기 → **Padlet 가져오기** → **학생에게 띄우기**.
- **띄우기·타이머** 탭에서는 어떤 웹 주소든, 큰 글씨 안내문, 활동 보드를 전원 화면에 동시에 띄울 수 있습니다.
  - **학생 화면 전체화면 요청**을 켜면 학생 화면 위에 큰 전체화면 버튼이 뜹니다.
  - 브라우저 정책상 남의 기기를 강제로 전체화면으로 바꿀 수는 없어서, 학생이 한 번 누르면 전환됩니다.
- **50분 타이머**: 50/40/30/15/5분 프리셋 또는 직접 입력 → **타이머 시작**. 학생 화면 상단에 남은 시간이 표시됩니다.
- 학생이 **손들기**를 누르면 **띄우기·타이머** 탭의 **손든 학생**에 나타나고, **확인**을 누르면 학생에게 알림이 갑니다.
- **전체 알림**에 문장을 입력하고 Enter를 누르면 모든 학생 화면에 안내가 뜹니다.

### 5) 화면 공유 (수시)

- **화면 공유** 탭 → **내 화면 공유** → 브라우저 선택 창에서 탭·창·전체 화면을 고릅니다.
  학생 화면 **맨 위**에 선생님 화면이 크게 나타나고, 학생이 늦게 들어와도 자동으로 다시 연결됩니다.
- 학생 화면 보기: 학생 카드의 **화면 요청** → 학생이 **허용** → **크게 보기**.
  **크게 보기**는 프로젝터에 그대로 띄울 수 있고, 안에서 **전체화면**을 누르면 브라우저 전체화면이 됩니다.
- **모두에게 요청**으로 접속한 학생 전원에게 한 번에 화면 공유를 요청할 수 있습니다.
- 화면 공유는 **https:// 또는 localhost**에서만 동작합니다. http:// 주소에서는 배너가 안내합니다.

### 6) 정리 (40~50분)

- **수업 종료**: 학생 화면에 종료 안내가 뜨고, 참가자·응답·보드 사본·이벤트가 즉시 삭제됩니다.
  선생님 컴퓨터의 보드 원본·PDF·게임 세트는 남아 다음 수업에 다시 쓸 수 있습니다.
- **수업 다시 시작**: 같은 참가 코드로 다시 열 수 있습니다(참가자는 새로 입장).
- **수업 삭제**: 대시보드 카드의 휴지통. 수업 행과 참가자 기록이 서버에서 완전히 사라집니다.

| 데이터 | 위치 | 비고 |

## 인터넷에서 준비할 것

배포에 필요한 계정·명령·TURN 설정은 [`docs/INTERNET_SETUP.md`](docs/INTERNET_SETUP.md)에, 배포만 빠르게 따라 하려면 [`docs/DEPLOY.md`](docs/DEPLOY.md)에 정리했습니다.
요약하면 **Cloudflare 계정 → `wrangler login` → D1 생성/ID 교체 → 원격 마이그레이션 → `TEACHER_PASSWORD`·`SESSION_SECRET` secret → 배포**이며,
R2 버킷은 만들 필요가 없습니다. 다른 네트워크의 학생과 화면 공유를 하려면 TURN 서버가 필요할 수 있습니다.

## 배포 전 체크리스트

1. `wrangler d1 create aic-db` 후 `wrangler.jsonc`의 `database_id` 교체 (현재 placeholder).
2. `wrangler secret put TEACHER_PASSWORD` — 선생님이 입력할 비밀번호(8자 이상).
3. `wrangler secret put SESSION_SECRET` — 16자 이상 임의 문자열. 기본값은 개발 전용입니다.
4. `bun run db:remote`로 원격 D1 마이그레이션 적용.
5. `bun run deploy` (`typecheck` → `vite build` → `wrangler deploy`).
6. 두 기기(교사 PC + 학생 기기)에서 비밀번호 입장·참가·보드·PDF·게임·화면 공유를 실제로 확인.
