# 보안과 개인정보

## 인증

- 선생님 입장: 단일 비밀번호. 값은 Cloudflare secret `TEACHER_PASSWORD`에만 있고,
  D1·앱 코드·브라우저 번들에는 저장하지 않습니다. 비교는 SHA-256 후 상수 시간 비교로 합니다.
- 세션: HMAC 서명 HttpOnly 쿠키(14일, SameSite=Lax, HTTPS에서 Secure). 세션 테이블 없음.
  쿠키의 소유자 id가 `tch_owner`가 아니면 거부하므로, 이전 계정 세션은 자동으로 무효화됩니다.
- 학생: 계정·쿠키 없음. 참가 토큰 원문은 학생 브라우저 localStorage에만 있고,
  D1에는 SHA-256 해시만 저장합니다.
- WebSocket 인증은 Worker에서 수행합니다. 쿼리 `token`이 있으면 항상 학생으로 처리해
  선생님 쿠키가 있는 브라우저에서도 학생 참가가 가능합니다.
- REST 변경 요청은 `Origin`을 검증합니다(`assertSameOrigin`).

## 권한 경계

- 수업 소유자 검증(Teacher RBAC): 수업 조회·수정·종료·이벤트·스냅샷.
- 학생은 자신의 참가 토큰으로만 상태를 읽고, 자신의 관측 이벤트·퀴즈 응답·학습지 답변을 보냅니다.
- 보드 카드 작성은 `allowStudentPosts`가 켜진 경우에만 허용하고, 서버가 길이·색·칸을 검증합니다.
- 파일 요청은 현재 배포된 학습지의 materialId와 일치할 때만 선생님에게 전달합니다.
- 파일 조각은 **선생님 역할만** 보낼 수 있고, 대상은 현재 접속 중인 학생으로 제한합니다.
  조각 크기(≤300K base64)·개수(≤96)·총 크기(≤12MB)를 검증하며 서버에 저장하지 않습니다.
- WebRTC 시그널링은 역할과 대상 학생 존재를 확인한 뒤 해당 소켓으로만 중계합니다.
  미디어 자체는 서버를 지나지 않습니다.

## 저장 최소화

| 데이터 | 위치 | 보관 |
| --- | --- | --- |
| 수업·참가자 | D1 | **수업 종료 즉시 참가자 삭제** |
| 실시간 상태·이벤트·퀴즈·게임·답변·입력 미리보기 | DO SQLite | **수업 종료 즉시 삭제** |
| 공유 중 보드 사본 | DO SQLite | 콘솔 종료 또는 수업 종료 시 삭제 |
| 보드·PDF | 선생님 브라우저 IndexedDB | 선생님이 삭제할 때까지 |
| 화면 영상 | WebRTC P2P | 저장하지 않음 |

- D1·DO·R2 어디에도 파일 바이트를 저장하지 않습니다.
- PDF는 학생이 요청한 동안 소켓으로 중계될 뿐, 서버 저장소에 남지 않습니다.

## 파일·콘텐츠 안전

- 학습지로는 `application/pdf`만 허용하고, 확장자와 크기를 확인합니다.
- 보드 카드 텍스트는 React가 이스케이프하며, 서버에서 280자로 제한합니다.
- PDF는 `Blob` URL로 표시하며 `X-Content-Type-Options: nosniff`를 유지합니다.
  출처가 확실한 수업 자료만 배포하세요.
- 응답에는 `Cache-Control: no-store`를 적용합니다.

## 브라우저 권한

- 화면 공유는 `getDisplayMedia` 사용자 선택이 필수입니다. 입장 화면에서 함께 시작을 선택해도
  브라우저 선택 창에서 학생이 직접 허용해야 하며, 원격으로 강제할 수 없습니다.
- 마이크는 사용하지 않습니다. `Permissions-Policy`에서 camera/geolocation을 차단하고
  display-capture는 self만 허용합니다.
- 학생 화면 요청은 배너로만 표시되며, 학생이 “공유 허용”을 눌러야 선택 창이 뜹니다.
- 입력 관찰은 선생님이 켠 동안 AIC의 학습지·보드·게임 입력값만 전송합니다.
  전역 키로깅, 다른 앱, 비밀번호 필드는 수집하지 않으며 학생 화면에 관찰 중임을 표시합니다.

## TURN 자격 증명

- `VITE_TURN_*` 값은 브라우저 번들에 포함되는 **공개 값**입니다. 장기 비밀번호를 넣지 말고,
  짧은 만료 시간의 임시 자격 증명을 발급하는 구성을 권장합니다.
- TURN 서버는 443/TCP(TLS)도 열어 학교 방화벽 환경을 고려하세요.

## 배포 시 필수

- `TEACHER_PASSWORD`를 `wrangler secret put`으로 설정(8자 이상).
- `SESSION_SECRET`을 `wrangler secret put`으로 설정.
- D1 `database_id`를 실제 ID로 교체.
- HTTPS 사용(Cloudflare 기본). 화면 공유는 HTTPS/localhost에서만 동작합니다.
- 개인정보 처리 방침, 학부모 동의, 미성년자 데이터 보호는 학교/기관 정책에 맞춰 검토.
