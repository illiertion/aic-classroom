# 집중 관측과 화면 공유

> v4에서도 **서버 녹화·업로드·R2 보관 기능은 없습니다.** 화면은 저장하지 않고,
> 학생이 허용한 동안 선생님이 실시간으로 보는 방식만 제공합니다.
> 대신 선생님이 **입력 관찰**을 켠 동안 AIC 활동 입력만 미리보기로 볼 수 있습니다.

## 집중 모드의 원칙

- 전체화면 **요청**은 학생 동작(입장 버튼) 안에서만 시도합니다. 자동 복구는 브라우저가 거부합니다.
- `fullscreenchange`, `visibilitychange`, `online/offline`, WebSocket 단절은 **관측값**으로 기록합니다.
- "확인 불가"는 이탈로 계산하지 않습니다. 권한이 없거나 브라우저가 상태를 알려주지 않을 수 있기 때문입니다.
- 동일 이벤트는 25초 안에 한 번만 기록해 알림 피로를 줄입니다.
- 키 입력은 페이지가 실제로 받은 `Esc`/단축키의 **발생 사실**만 남기며, 전역 내용 수집·부정행위 판정은 하지 않습니다.
- **입력 관찰**은 별도 토글입니다. 켜면 학생 화면에 “선생님이 활동 입력을 보고 있습니다”가 표시되고,
  학습지·보드·게임 입력값만 0.5초 디바운스로 전송됩니다. 끄면 전송되지 않습니다.

## 화면 공유 흐름

### 선생님 → 학급

1. 선생님이 **화면 공유 → 내 화면 공유**를 누릅니다.
2. 브라우저 선택 창에서 탭/창/전체 화면을 고릅니다(사용자 동작 필수).
3. 선생님 브라우저가 접속 중인 학생마다 `RTCPeerConnection`을 만들고 offer를 보냅니다.
4. 학생은 자동으로 answer하고 영상을 표시합니다. 별도 허용 창은 없습니다(받기만 하므로).
5. 공유 중지·트랙 종료·콘솔 종료 시 모든 피어를 닫고 학생 화면에서 영상이 사라집니다.

### 학생 → 선생님

1. 선생님이 학생 카드에서 **화면 요청**을 누르면 학생에게 배너가 뜹니다.
   (학생이 먼저 **내 화면 공유**를 눌러도 됩니다.)
2. 학생이 **공유 허용**을 누르면 브라우저 선택 창이 열립니다. 입장 화면에서 “전체화면·내 화면 공유”를
   켜 두면 입장 버튼 클릭 안에서 같은 선택 창이 뜨고, 선택을 취소해도 수업에는 참가됩니다.
3. 학생이 고른 화면만 offer로 전송되고, 선생님 콘솔의 해당 학생 칸에 영상이 나타납니다.
4. 어느 쪽이든 **중지**를 누르면 트랙이 종료되고 상대 화면에서 사라집니다.

### 프라이버시

- 영상은 P2P로만 흐르고 서버·D1·R2에 저장되지 않습니다.
- 학생 화면은 학생의 브라우저 선택·허용 없이는 절대 전송되지 않습니다.
- 화면 공유 시작/중지/거부는 이벤트 로그에 관측 사실로 남습니다.
- 선생님 콘솔을 닫으면 보드·PDF 접근과 화면 공유가 함께 중단됩니다.

## 연결이 안 될 때

- 같은 Wi-Fi: 공개 STUN으로 대부분 연결됩니다.
- 다른 네트워크(LTE, 집): 학교/기관 방화벽이 UDP를 막으면 TURN이 필요합니다.
- TURN 설정은 빌드 시 `VITE_TURN_URL`·`VITE_TURN_USERNAME`·`VITE_TURN_CREDENTIAL`로 넣습니다.
- iOS Safari는 화면 공유/백그라운드 전환에서 제한이 큽니다. 학생에게 “저장” 또는 다른 기기를 안내하세요.

## 검증 상태

- 입력 관찰 토글·전달·끄기, 스펠링/OX 채점: 자동 스모크 통과.
- 보드 공유·학생 카드·콘솔 종료 시 삭제: 자동 스모크 통과.
- 수업 종료 즉시 참가자·답변·보드·이벤트 삭제: 자동 스모크 통과.
- PDF 메타데이터·요청·조각 중계: 자동 스모크 통과. 실제 PDF 재조립·미리보기는 브라우저 수동 확인 필요.
- WebRTC 시그널링 중계: 자동 스모크 통과. 실제 영상 연결은 서로 다른 두 기기에서 수동 확인 필요.
- Android/iOS 실기기, 블루투스 키보드, 실제 TURN 환경은 이 컴퓨터에서 검증하지 못했습니다.
