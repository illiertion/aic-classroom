# 한계

## 브라우저가 할 수 없는 일 (구현하지 않음)

| 요구 | 현실 |
| --- | --- |
| Chrome 단축키 차단 | 웹페이지는 브라우저 단축키를 가로챌 수 없습니다. 페이지가 받은 입력만 관측합니다. |
| `ESC` 전체화면 종료 차단 | Fullscreen API 정책상 불가능합니다. 해제를 관측·기록만 합니다. |
| Android 홈 버튼·앱 전환 차단 | 불가능합니다. `visibilitychange`/연결 끊김으로 흔적만 남습니다. |
| 학생 동의 없는 화면 공유·녹화 | 불가능하며 구현하지 않았습니다. `getDisplayMedia`는 사용자 선택이 필수입니다. |
| 선생님 콘솔이 꺼진 뒤 자료 접근 | 보드·PDF는 선생님 PC에 있으므로 콘솔이 닫히면 학생이 받을 수 없습니다. |
| 브라우저 종료 후 화면 공유 지속 | 불가능합니다. 탭이 닫히면 피어와 트랙이 끝납니다. |
| 전체화면 자동 복구 | 사용자 동작 없이 호출하면 브라우저가 거부합니다. 버튼이 필요합니다. |
| 부정행위 판정 | 하지 않습니다. 모든 표시는 “관측”입니다. |
| 키 입력 내용 수집 | 전역 키로깅은 하지 않습니다. 선생님이 입력 관찰을 켠 동안 AIC 활동 입력값만 미리보기로 전송합니다. |
| 다른 앱·비밀번호 입력 보기 | 불가능합니다. 브라우저는 다른 앱의 입력을 제공하지 않으며, AIC도 비밀번호 필드를 수집하지 않습니다. |
| 학생 화면 공유 강제 | 불가능합니다. 입장 시 선택 창을 띄울 수는 있지만 학생이 허용해야 시작됩니다. |

## v4에서 의도적으로 없는 것

- **서버 녹화·업로드·보관**: R2와 미디어 파이프라인을 제거했습니다.
- **파일 서버 보관**: PDF는 선생님 브라우저에만 있고, 수업 중에만 중계됩니다.
- **다른 PC와 보드·게임 자동 동기화**: 보드함과 게임 세트는 브라우저 프로필 단위입니다.
  JSON 내보내기/가져오기로 옮깁니다.
- **Padlet 강제 임베드**: Padlet이 iframe을 막는 보드는 새 창으로 열어야 합니다.
- **수업 종료 후 기록 복원**: 종료 즉시 파기하므로 되돌릴 수 없습니다.

## 플랫폼·환경 차이

- **iOS/iPadOS Safari**: PDF 인라인 표시가 제한적이고, 화면 공유·백그라운드 전환이 불안정합니다.
  학생에게 “저장” 버튼을 안내하세요.
- **Android Chrome**: 탭 공유만 허용되는 버전이 있고, 시스템 오디오 공유가 제한됩니다.
- **학교 방화벽**: UDP 차단 시 화면 공유가 실패할 수 있습니다. TURN(443/TCP)이 필요합니다.
- **Bun + Wrangler**: 이 컴퓨터에서는 Bun으로 `wrangler dev`를 실행하면 프록시 오류가 납니다.
  `.tools/node`의 Node 22로 실행하세요.

## 이 환경에서 검증하지 못한 것

- Android/iOS 실기기, 블루투스 키보드, 실제 홈 버튼/ESC
- 서로 다른 두 기기·다른 네트워크에서의 실제 WebRTC 영상 연결
- 실제 PDF 12MB급 파일의 재조립·모바일 미리보기
- 원격 Cloudflare 배포(D1/DO/cron/HTTPS/TURN)
- 장시간 수업에서의 연결 안정성
- 실제 Padlet 보드의 iframe 표시 여부(보드별 설정에 따라 다름)
- 실제 기기에서 입장과 동시에 뜨는 화면 선택 창의 브라우저별 동작
- 실제 게임 세트를 여러 학급에서 장시간 진행하는 경우의 UI

## 운영 시 유의

- `wrangler.jsonc`의 D1 `database_id`는 placeholder입니다.
- `TEACHER_PASSWORD`와 `SESSION_SECRET`은 반드시 Cloudflare secret으로 설정하세요.
  로컬 `.dev.vars`는 gitignore 대상입니다.
- 보드·PDF는 선생님 PC에만 있으므로 수업 중 콘솔 탭을 닫거나 PC를 절전하지 마세요.
- 개인정보 처리 방침·학부모 동의·미성년자 보호는 학교/기관 정책에 맞춰 별도 검토해야 합니다.
